# CodeAlpha Image Gallery

A responsive image gallery website built using HTML, CSS, and JavaScript as part of my CodeAlpha Frontend Development Internship.

## Features

- Responsive image gallery
- Category-based image filtering
- Lightbox image viewer
- Next and Previous image navigation
- Keyboard navigation using Arrow keys
- Escape key to close the lightbox
- Hover effects and smooth transitions
- Responsive design for desktop, tablet, and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Categories

- All Photos
- Nature
- Animals
- Cities
- Travel
